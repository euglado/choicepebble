# Güvenlik / Security

Token sızıntısında önce Discord Developer Portal → Bot → Reset Token ile yenileyin ve botu güvenle yeniden yapılandırın. Gizli bilgiyi sorunlara veya PR'lara eklemeyin. Açıkta duran mesajı silmek, tokenı yenilemenin yerine geçmez.

For a vulnerability, use this repository's **Security → Report a vulnerability** private reporting option if available. If unavailable, open only a minimal public issue requesting a private reporting channel, without exploit details, credentials, voter IDs or private server content. A response time or security audit is not guaranteed. Only the current main branch is maintained.

No privileged intents or Administrator permission are needed. Poll voter IDs are temporary RAM records; Discord public messages and hosting-provider retention are separate. This bot is not a secret-ballot system. Never use it to collect sensitive personal data. See README for limits, safe setup and retention behavior.
